# Calculator Subproject - Improvements

The current Calculator subproject implementation provides a functional basic calculator with arithmetic operations. The following improvements are recommended:

- Add support for decimal numbers and negative numbers.
- Add keyboard input support for calculator operations.
- Implement more advanced operations such as percentage, square root, etc.
- Improve UI styling and responsiveness for various devices.
- Add error handling for division by zero and invalid operations.
- Add a history feature to track previous calculations.
- Prepare documentation and deployment scripts.
