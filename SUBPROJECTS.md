# Documentação dos Subprojetos

Este documento descreve os subprojetos e funcionalidades presentes na aplicação React, conforme as rotas definidas em `src/App.jsx`.

## Lista de Subprojetos

- **/** (Welcome)  
  Página inicial de boas-vindas da aplicação.

- **/blog**  
  Projeto de Blog com listagem de posts.

- **/blog/content/:id**  
  Visualização do conteúdo detalhado de um post do blog.

- **/booking**  
  Sistema de agendamento.

- **/calculator**  
  Aplicação de calculadora.

- **/clone**  
  Projeto de clone de sites populares.

- **/clone/hbo**  
  Clone da interface HBO.

- **/clone/hbo/sign**  
  Página de login do clone HBO.

- **/clone/discord**  
  Clone da interface Discord.

- **/clone/youtube**  
  Clone da interface YouTube.

- **/cms**  
  Sistema de gerenciamento de conteúdo (CMS).

- **/crud**  
  Aplicação CRUD (Create, Read, Update, Delete).

- **/dashboard**  
  Painel de controle (Dashboard).

- **/delivery**  
  Sistema de entrega.

- **/ecommerce**  
  Loja virtual (Ecommerce).

- **/gallery**  
  Galeria de imagens.

- **/gallery/content/:id**  
  Visualização detalhada de item da galeria.

- **/playlist**  
  Gerenciador de playlists.

- **/portfolio**  
  Portfólio pessoal ou profissional.

- **/quiz**  
  Aplicação de quiz.

- **/quiz/:id**  
  Visualização detalhada de quiz.

- **/ranking**  
  Sistema de ranking.

- **/schedule**  
  Sistema de agendamento e calendário.

- **/siteapi**  
  Projeto de API para site.

- **/socialmedia**  
  Projeto de rede social.

- **/tictactoe**  
  Jogo da velha (Tic Tac Toe).

- **/weather**  
  Aplicação de previsão do tempo.

- **/template**  
  Template de projeto.

## Observações

Cada subprojeto está organizado em sua respectiva pasta dentro de `src/Pages/Projects/` ou `src/Pages/`.

Esta documentação pode ser expandida com descrições detalhadas, instruções de uso e exemplos conforme necessário.
